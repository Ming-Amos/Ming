## 贡献归属与限制

Ming 的适配器、校验器、服务接口、网页及核心修复由 **Bob** 实现。**Codex** 负责独立审查、HTTP/校验边界验证，以及对 `scripts/run-stage-b-ui-tests.mjs` 的验证脚本修正：

- 从所属工作区解析依赖，使用 Vite 实际 JavaScript 入口，并保留启动错误输出。
- 针对未配置错误提示、计划指纹和具体结果区域准确定位。
- 绑定本轮 runId，检查截图归属及真实加载；实际点击网页按钮重跑，核对新运行、原确认记录和相同计划指纹。
- 等待第二轮结果实际渲染，并检查执行按钮在完成后重新可用。

这些是验证脚本与审查贡献，不计作 Bob 核心实现。当前生成验证使用明确标注的本地测试夹具，独立 HTTP 验证使用本地模拟服务和假密钥。真实供应商鉴权、网络兼容性、模型输出质量及 live 端到端流程尚未验证；需配置真实供应商后另行验收。
