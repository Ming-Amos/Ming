## Current capability and evidence checks

The current local product supports persisted user projects, same-origin local development URLs, self-contained HTML imports, saved requirements, manual plans and revisions, explicit confirmation, real browser execution, cancellation, restart recovery, history and report export. The configurable model connection is optional; saving settings makes no model call, while connection testing and generation are explicit requests that may incur provider charges. No external provider has been quality-tested.

The expanded local MCP adapter exposes 12 tools for project discovery, confirmed acceptance, progress, cancellation, evidence and repair. A coding agent still needs its own authorized editing capabilities; creating a task does not wake it automatically.
